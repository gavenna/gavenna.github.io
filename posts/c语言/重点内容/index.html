作用域
#

  • 全局作用域

    函数外部定义，全局有效

  • 局部作用域

    函数内部定义，局部有效

  • 文件作用域

    用static修饰，仅本文件有效

生命周期
#

  • 自动变量

    在进入定义它们的代码块时创建，代码块结束时销毁

  • 静态变量

    在程序执行前创建，程序结束时销毁

  • 动态变量

    通过动态内存分配，通过释放内存销毁

内存对齐
#

  • 对齐的内存访问通常比未对齐的访问更快
  • 某些硬件或指令集可能要求特定类型的数据必须按照一定的边界对齐。违反这些要求可能导致硬件异常。
  • 当不同的编译器或平台间进行数据交换时，对齐规则的一致性是必要的

对齐规则
#

自然对齐
#

按照数据类型进行对齐，如int​通常为4字节对齐

结构体对齐
#

按照内存最大的成员对齐，或通过#pragma pack或__attribute__((aligned))​指定对齐位数

联合体对齐
#

按照内存最大的数据类型对齐，但共用同一内存空间

掩码
#

掩码（Mask）是一种常用的位操作技术，它利用位运算符来创建特定的位模式，以便对数据的特定位进行操作

掩码是一个位序列，通常与特定的位位置相关联，用于选择（屏蔽）或清除（屏蔽）数据中的特定位。掩码通常与按位与（AND）、按位或（OR）、按位异或（XOR）和按位取反（NOT）运算符一起使用

创建方式
#

掩码通常是通过将1位移位操作来创建的

选择特定的位
#

​unsigned int mask = 1 << n; // 选择第n位​

选择一系列位
#

​unsigned int mask = (1 << (n + 1)) - 1; // 选择从第0位到第n位​

具体使用
#

设置特定位，通过按位或
#

​data |= (1 << n); // 将第n位设置为1​

清楚特定位，通过按位与
#

​data &= ~(1 << n); //将第n位设置为0​

切换特定位，通过按位异或
#

​data ^= (1 << n); // 切换第n位的值（0变1，1变0）​

检查特定位（使用按位与运算符）
#

​int bit = (data & (1 << n)) != 0; // 检查第n位是否为1​

位域操作
#

位域打包和解包是C语言中利用位操作将多个数据项组合存储在单个变量中，以及从该变量中提取这些数据项的过程

特点
#
  • 节省内存
  • 数据压缩
位域打包
#

假设我们有三个布尔值 a​, b​, c​ 和一个8位的无符号整数 value​，我们想要将这三个布尔值打包到 value​ 的前三位

// 打包函数
unsigned int pack_bits(unsigned int a, unsigned int b, unsigned int c) {
    unsigned int value = 0;
    value |= (a << 2); // 将a放在第3位
    value |= (b << 1); // 将b放在第2位
    value |= c;        // 将c放在第1位
    return value;
}
位域解包
#
// 解包函数
void unpack_bits(unsigned int value, unsigned int *a, unsigned int *b, unsigned int *c) {
    *a = (value >> 2) & 1; // 提取第3位并清除其他位
    *b = (value >> 1) & 1; // 提取第2位并清除其他位
    *c = value & 1;        // 提取第1位并清除其他位
}

volatile的用法
#

防止编译器对变量进行优化，确保对变量的访问是直接从内存中进行，而不是使用寄存器或缓存

使用场景
#

  • 硬件寄存器：在嵌入式系统或与硬件交互的程序中，volatile 关键字用于声明硬件寄存器或与硬件相关的变量。这确保了每次访问这些变量时都直接与硬件交互，而不是使用寄存器或缓存
  • 中断服务程序：在中断服务程序中访问的共享变量应该被声明为 volatile​，以确保在中断服务程序中修改的变量对其他线程可见。
  • 多线程环境：在多线程环境中，volatile​ 可以用于确保一个线程对变量的修改对其他线程是可见的，但它不能保证原子性。

注意事项
#

​volatile​ 关键字只能保证变量的可见性，不能保证原子性。如果需要原子性，应该使用锁或其他同步机制。

解决方法
#
  1. 使用原子操作：许多编程语言提供了原子操作库，例如 C11 的 <stdatomic.h>​。这些库提供了原子类型的变量和操作，可以确保操作的原子性。
  2. 使用锁：在多线程环境中，可以使用锁（例如互斥锁）来保护共享资源，确保在同一时间只有一个线程可以访问该资源。这可以防止竞态条件，并确保操作的原子性。
  3. 使用原子类型：一些编程语言提供了原子类型，例如 C++11 的 std::atomic​。这些类型提供了原子操作，可以确保操作的原子性。

const修饰变量存放位置
#

若const修饰变量为局部变量，则该变量位于栈上，且可通过指针修改

若const修饰变量为全局变量，则该变量位于.rodata段，未出示化的存放在.bss，不可修改

c++程序调用c函数（extern “C“的使用）
#

由于c++中需要支持函数重载，所以c和c++中对同一个函数经过编译后生成的函数名是不同的，这就会导致一个问题，如果在c++中调用一个使用c语言编写模块中的某个函数，c++是按照c++的名称修饰方式来查找并链接这个函数，就会发生链接错误。

c函数：void func()，被编译成函数：func

c++函数： void func(){}，被编译成函数：_Z4funcv

// my_module.h
#pragma once
#include<stdio.h>
 
#ifdef __cplusplus
extern "C"{
#endif
 
	void func1();
	int func2(int a,int b);
 
#ifdef __cplusplus
}
#endif
 
 
// my_module.c
#include "my_module.h"
 
void func1() {
  printf("hello world.");
}
int func2(int a, int b) {
  return a+b;
}
 
// test.cpp
#include "my_module.h"
#include<iostream>
using namespace std;
 
int main() {
  func1();
  cout << func2(10, 20) << endl;
}

sizeof详解
#

概述
#

Sizeof是C/C++中的关键字，它是一个运算符，其作用是取得一个对象(数据类型或者数据对象)的长度(即占用内存的大小，以byte为单位)。

其中类型包含基本数据类型(不包括void)、用户自定义类型(结构体、类)、函数类型。数据对象是指用前面提到的类型定义的普通变量和指针变量(包含void指针)。

不同类型的数据的大小在不同的平台下有所区别，但是c标准规定所有编译平台都应该保证sizeof(char)等于1

​sizeof​ 是在编译时确定的，而不是在运行时。sizeof​ 运算符用于确定变量或数据类型在内存中所占的字节数。由于它是一个编译时运算符，所以其结果是由编译器在编译程序的时候计算出来的，并且这个结果在程序运行过程中是不会改变的

特性
#

  • sizeof是运算符，不是函数；

  • sizeof不能求得void类型的长度；

  • sizeof能求得void类型的指针的长度；

  • sizeof能求得静态分配内存的数组的长度!

  • sizeof不能求得动态分配的内存的大小!

  • sizeof不能对不完整的数组求长度；

  • 当表达式作为sizeof的操作数时，它返回表达式的计算结果的类型大小，但是它不对表达式求值！

  • sizeof可以对函数调用求大小，并且求得的大小等于返回类型的大小，但是不执行函数体！

  • sizeof求得的结构体(及其对象)的大小并不等于各个数据成员对象的大小之和！

  • sizeof不能用于求结构体的位域成员的大小，但是可以求得包含位域成员的结构体的大小！
