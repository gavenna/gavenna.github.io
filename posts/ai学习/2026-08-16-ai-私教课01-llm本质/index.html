AI 私教课 第1课 — LLM 到底在做什么
#

教学方式：苏格拉底式（Hermes 提问 → 我回答 → 反馈纠错 → 追问）。本课 6 问全部答对，并独立提出了 3 个高质量质疑。 课程入口：AI 私教课系列（苏格拉底式教学记录）

学习目标
#

  • 自主推导 LLM 的核心机制（生成方式 / 选择机制 / 训练来源 / 记忆本质）
  • 捡回 4 个概率概念（条件概率 / 概率分布 / 熵 / 期望值），并映射到 AI 现象
  • 理解 temperature 的真实作用、采样 vs 贪心、为什么写代码也要温度 > 0

一、六问六答 —— 自主推导 LLM 本质
#

#问题我的答案结论关键点
1文字发给 AI 第一步变成什么？变成英文❌ 差一点不是英文，是切块编号（token 化）——每个 token 有数字 ID
2AI 是整段想好再写，还是逐字蹦？逐字蹦✅观察：Claude Code 打字一个字一个字出
3决定下一个字的依据？给候选打分选分高的✅条件概率：对候选字分配概率
4每次选最高分会怎样？千篇一律复读机✅所以 AI 故意不选最高 → temperature 存在的原因
5打分能力从哪来？喂海量文本自学✅预训练 = 读全人类文本找统计规律
6读了那么多为什么记不住细节？压缩成规律，细节丢失✅参数 = 压缩后的统计规律，不是记忆

一句话总结（用自己的话）：LLM 是一个「把全人类文本压缩成规律、然后一个字一个字按规律往外蹦」的机器。

由机制解释现象
#

现象机制解释
AI 一本正经胡说（幻觉）故意不选最高分（temperature 冒险）+ 熵高时随便挑
记不住长对话 / 昨天的事只有压缩后的规律，没有真正的记忆存储
知识有截止日期训练完就封存，规律不再更新
DeepSeek 为什么便宜压缩得狠（MoE 少激活参数）→ 推理便宜（第 3 课伏笔）

二、四个概率概念（补地基）
#

1. 条件概率 P(B|A) —— 概率论的心脏
#

  • 定义：在已知 A 的前提下，B 发生的概率。重点是「如果……那么……有多大概率」。
  • AI 对应：蹦字就是条件概率 P(下一个字 | 上文)。同一个「今天天气真」，换不同候选字概率完全不同。
  • 推论：AI 的「理解」= 对不同条件给出不同概率。prompt 写清楚 = 缩小条件 → 抬高正确概率。

2. 概率分布 —— 权重的榜单
#

  • 定义：所有可能结果的概率加起来必须 = 1（100% 的饼按权重分配）。
  • AI 对应：给所有候选字分配概率，总和为 1。
  • 推论：temperature = 重新分配这块饼的形状（见第四节）。

3. 熵 —— 不确定性的尺子
#

  • 定义：衡量分布有多平均/不确定。概率集中 → 熵低（确定）；摊平 → 熵高（犹豫）。
  • AI 对应：AI 的「犹豫」= 熵高（候选概率都差不多）。「1+1=2」秒答 = 熵极低。
  • 推论：「自信地错」最危险——熵低 + 内容错误时，人不会去验证。⚠️ 不能用回答速度判断熵（网络波动干扰），正确做法：直接问「你有多大把握（0-100 分）」。

4. 期望值 / 大数定律 —— 概率的长期预言
#

  • 定义：长期重复概率事件，结果趋近平均值。单次不可预测，长期必然收敛。
  • AI 对应：单次修改 95% 概率改对，改 100 次期望翻车 5 次 → 次数多了该发生的必然发生。
  • 推论：测试不改变 AI 出错概率 p，改变的是错误传播半径——把「错误传染后续 50 步」压缩成「错误损失 1 步」。外部确定性对抗内部概率性。

总纲：AI 是「给定条件 → 分配概率 → 采样输出」的机器；所有调优（prompt / temperature / 测试）都是在改造这个概率系统。

三、采样 vs 贪心 —— 冷门候选为什么有机会
#

我的质疑（本课亮点 1）
#

「非线性改变我理解，但最后再怎么放，大的还是大，为什么概率小的有机会？AI 不是只会选概率最大的吗？」

误解根源：以为 AI 是「选最大」。真相：AI 不是选最大的，是「按概率抽签」。

掷骰子模型
#

  • 每个候选字 = 骰子的一面，面的大小 = 概率
  • AI 生成时掷一个 0~1 随机数，落在哪个区间选哪个字
  • 冷门候选（概率 0.000001）也占一小块地盘 → 随机数总有万分之一机会落在上面

temperature 的真实作用
#

温度骰子面形态效果
低 (0.1)第一名占 98%随机数几乎总落它头上 → 稳定 / 复读机
高 (1.5)摊平随机数容易落冷门区 → 有创意 / 爱胡说
0（贪心）第一名占 100%永远选最大 → 确定 / 可复现 / 无聊

温度改的不是「第一名是谁」，是「冷门候选被抽中的概率」。

四、temperature 的数学机制（我的质疑 2）
#

我的质疑
#

「如果这个操作是对所有对象的话，那大的还是大，小的还是小，最后选的没变啊。」

质疑成立——线性缩放确实不改排序。真相：

softmax 非线性
#

概率 = e^(分数/温度) / Σ e^(分数/温度)

e^x 是非线性函数 → 除以温度后在指数空间操作 → 相对差距被改变：

温度e^x 差距结果
0.1放大 2.2 万倍第一名碾压
1.5只剩 2 倍冷门有机会
  • 温度→∞：所有概率趋近相等（完全随机）
  • 温度→0：只选第一名（贪心，确定性输出）

五、为什么写代码温度也要 > 0（我的追问）
#

「写代码不是追求稳定吗？为什么温度也要大于 0？」

核心：贪心 = 最流行 ≠ 最正确
#

  • 贪心选的是「训练数据里最常见的写法」——而最常见恰恰意味着最平庸、可能有 bug
  • 贪心 = 没有回头路：第 1 步选错（最常见但有坑），后面全部建立在错误上，永远没机会换路
  • 采样 = 每步有小概率「跳出惯性」→ 遇到最熟悉的路径有 bug 时能换一条思路

工程真相
#

错误做法正确做法
温度 = 0 锁死输出中等温度 + 验证循环
保证「每次生成都一样」保证「每次生成的都是对的」
靠锁死防错靠测试抓错

稳定性来自验证，不来自确定性。 佐证：AI 评测强制 temperature=0 是为了复现实验，不是结果最好——很多任务多次采样取多数票（Self-Consistency）反而正确率更高。

六、我的独立公理化推理（本课最大亮点）
#

「为什么概率不能超过 100%、不能为负？超过 100 代表必然发生（和 100% 一样），低于 0 代表不可能发生（和 0% 一样）。必然和不可能都是绝对的，用一个唯一值代表即可；但偶然是相对的，所以要能区分大小。」

这就是 1933 年科尔莫戈罗夫概率三公理的独立重建：

公理内容我的直觉对应
非负性概率 ≥ 0「不能有 -1」
规范性必然事件 = 1「100% 就是必然」
可加性互斥事件相加 = 1「所有候选加起来 = 100%」

「01 之间才能区分偶然程度」= 概率作为信念程度的哲学基础（贝叶斯视角）。 注：内部权重（logits）可以超过 1，归一化成概率后必须落回 01——归一化让「必然 = 1」成为统一基准。

七、测验与批改
#

#题目我的答案批改
1prompt 变长为什么回答变好条件更精准 → 正确概率增加✅ 满分
2同问题两次答案不一样，哪个概念解释条件概率采样（非总选最高）✅ + 追问「强制选最高就确定？」→ 对，温度=0 贪心，评测靠它复现
3每次修改后跑测试，期望值解释让坏期望变小/别变大太快🟡 方向对，修正：测试不改 p（出错概率），改 L（错误传播半径）——期望损失从随次数增长变成与次数无关

八、课程总结
#

知识收获
#

  • LLM = 条件概率 + 概率分布 + 采样 的机器
  • 4 个概率概念全部映射到 AI 现象（犹豫/幻觉/记不住/越改越乱）
  • temperature 的数学本质（softmax 非线性）+ 工程本质（冷门候选的抽中概率）
  • 稳定性 = 验证而非确定性

能力信号
#

  • 独立重建概率公理（第一性原理思维）
  • 抓出老师讲解中的漏洞（线性缩放质疑成立）
  • 纠正熵的误用（速度判断不可靠）
  • 这些正是「思维模型」维度的强项，后续课程应继续用质疑驱动

学习方式验证
#

「70% AI 教 + 30% 书补地基」路线可行——书的核心已被课程覆盖，无需额外阅读《这就是ChatGPT》。
